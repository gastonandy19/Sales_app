# Sales App

## Project Description
Sales App is a simple web application built to help small shop owners record and track daily sales. Instead of using a terminal script, users can open the application in a web browser, enter sales information, and view updates easily.

## Features
- Record daily sales
- Store sales information
- View sales records
- Simple and user-friendly web interface
- Real-time updates as users enter sales

## Technologies Used
- Python
- Flask
- HTML
- CSS
- Git and GitHub

## Project Structure

Sales_app/ │ ├── app.py ├── templates/ │   └── index.html ├── static/ │   └── style.css └── README.md

## How to Run the Application

1. Clone the repository:

git clone https://github.com/gastonandy19/Sales_app.git

2. Open the project folder:

cd Sales_app

3. Install Flask:

pip install flask

4. Run the application:

python app.py

5. Open your browser and visit:

http://127.0.0.1:5000
